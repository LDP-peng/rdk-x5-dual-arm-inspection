01 / OVERVIEW

项目概览

把“到达能力”和“操作能力”解耦，减少人员进入危险现场的频次。

这是一套“移动底盘 + 双机械臂主从遥操作”的巡检作业原型。车端负责自主到达、雷达避障和定点停车； 操作端保留人的判断能力，通过主臂把动作实时映射到车载从臂。系统不追求无人化全自动作业， 而是先解决现场最实际的问题：人不必进入，手仍然可以伸进去。

01 / REACH

先到得了

里程计闭环完成 2 m 级巡航，N10P 雷达持续守护前向安全距离，到点自动停车。

02 / OPERATE

再够得着

主臂关节流经 ROS 2 传到车端，从臂复刻动作，执行夹取、按钮、阀门等接触式作业。

03 / SAFE

最后可复现

当前位姿作为零点、软限位、幅度缩放和急停保护，降低异构机械臂首次联调的冲击。

02 / PROBLEM

场景痛点

传统巡检设备解决了“看见”，却没有解决“碰到”。

PAIN 01

到不了

变电站、管廊、机房、夜间站厅等场景存在危险源或狭窄通道，人员进入成本高。

PAIN 02

够不着

固定摄像头只能查看，无法按下按钮、拉开门锁、转动阀门或取走异物。

PAIN 03

不稳定

重复巡检强度大，人工状态容易波动；高风险区域也不适合长时间驻留。

因此，本项目把任务拆成两段：底盘把人送到作业点附近的“安全观察位”， 机械臂代替人手完成接触动作。人保留判断，机器承担到达与高风险执行。

03 / SOLUTION

系统方案

异构主从映射，不要求两台机械臂同型号、同尺寸。

ARRIVAL / 到达端

移动底盘自主执行

车端 RDK X5 读取 /odom 与 /scan，按任务状态机输出 /cmd_vel。 正常段按航点前进，前向 0.45 m 出现障碍时减速并停车；确认安全后继续，最终在巡检点停车。

目标：x = 2.0 m
安全阈值：front_range < 0.45 m → stop
停车：到达窗口 + 零速保持
MANIPULATION / 作业端

人机协同完成操作

主臂采集关节角，经 ROS 2 主题传到车端。从臂不复制主臂的绝对角度，而是复制相对运动量， 从而适配不同型号、不同零位和不同安装姿态。

q_target = clamp(q_zero + scale · s · Δq)
scale = 0.3　s = [+1, -1, +1, +1, +1]
已实现

异构适配

主臂与从臂型号不同，仍可建立动作映射。

已实现

安全启动

以当前位姿为零点，避免上电瞬间大幅跳动。

已实现

分层解耦

底盘、雷达、主臂、从臂可独立诊断和降级。

数据链路分为两条：控制链路（主臂关节流 → 从臂 I2C）与移动链路（里程计 + 雷达 → 底盘）。 两条链路独立启动、独立检查，任何一条异常都不影响另一条的安全停机。

05 / TELEOPERATION

主从遥操作实现

复制“相对运动”，而不是复制“绝对角度”。

主臂与从臂的型号、连杆长度、零位定义和安装方向都不同。系统在启动时分别记录主臂与从臂的当前位姿， 之后只传输主臂相对零位的增量，再按比例叠加到从臂零位上。这样既避免上电跳变，也让异构机械臂可以用同一套控制逻辑。

q_slave_target[i] = clamp( q_slave_zero[i] + scale × sign[i] × ( q_master[i] − q_master_zero[i] ) )

scale = 0.3　　sign = [+1, −1, +1, +1, +1]　　transport = ROS 2 DDS / I2C 0x15
WHY RELATIVE

异构臂可以对齐

相对映射消除了绝对零位差异；幅度缩放 0.3 让主臂的大幅动作转换为从臂可控的小幅动作，减少碰撞风险。

SAFETY

三点保护

启动时以当前位姿为零点；每个关节做软限位；主臂数据中断时停止继续下发，不让从臂追一个已经不存在的目标。

T0

双端零点采样

主臂和从臂保持自然姿态，系统分别记录当前关节角，作为本次会话的参考零位。

T1

主臂关节流发布

主臂节点约 15 Hz 发布 /master/joint_states，包含 5 个关节与夹爪通道。

T2

车端接收与映射

车端按索引对齐关节，执行方向修正、幅度缩放和软限位，生成从臂目标角。

T3

I2C 下发到从臂

通过总线 5、地址 0x15 驱动 Dofbot 的 5 个关节与夹爪；读不到设备时直接拒绝启动。

T4

持续闭环与恢复

操作过程中保持低延迟跟随；松开或退出前先扶住主臂，避免主臂掉电下落。

控制项当前参数工程目的
主臂数据/master/joint_states · 约 15 Hz保证动作连续，同时避免把高频抖动直接放大到从臂。
映射幅度scale = 0.3先保证安全与可演示，再逐步放大动作范围。
方向修正第二关节 sign = −1解决主从安装方向不一致导致的镜像运动。
从臂通信I2C bus 5 · address 0x155 关节 + 夹爪；接线未通过时不允许带故障启动。
06 / AUTONOMY

底盘自主与避障

现场空旷，最终主线采用“里程计航点 + 雷达安全层”。

演示场地缺少稳定、可重复利用的建图特征，SLAM 与 AMCL 的现场收敛成本高。 最终演示不再把建图作为前置条件，而是让底盘按里程计闭环前进到 2 m 巡检点； N10P 雷达在全程提供前向安全距离，遇障减速、停车，确认后继续或绕行。

STEP 01

巡航

读取 /odom，输出受限速度，朝目标距离前进。

STEP 02

守护

读取 /scan 前向扇区；小于 0.45 m 时触发安全停机。

STEP 03

到达

进入停车窗口后零速保持，等待操作员接管机械臂。

正常段：odom → distance_error → /cmd_vel 安全层：/scan（前向扇区）→ 0.45 m 阈值 → 减速 / 停车 任务层：到达 → 作业等待 → 回车确认 → 返航
最终演示主线

为什么保留里程计航点

演示距离固定、起点可控，里程计方案启动快、依赖少、复现稳定。它让评委在最短时间内看到完整闭环，而不是把时间消耗在定位收敛上。

扩展能力

SLAM / Nav2 的定位

建图、AMCL 与 Nav2 已保留为后续能力，用于有明确地图和固定巡检路线的场地；本次空旷演示不作为最终链路。

07 / DEMO

演示流程

一条完整链路：自主到达 → 人接管 → 从臂作业 → 自动返航。

00 s

启动与自检

确认 /odom、/scan、主臂关节流和从臂 I2C 0x15 全部在线；车头前方 2 m 内无人、无障碍。

10 s

自主前进

车端任务节点按里程计闭环向巡检点移动，速度保持低速，雷达持续监测前向安全距离。

35 s

避障与通过

若前向小于 0.45 m，底盘先减速再停车；障碍解除后恢复，或按演示预案从可用侧向空间绕行。

50 s

定点停车

进入 2 m 目标窗口后零速保持，切换到主从遥操作，从臂进入待命姿态。

60 s

操作员接管

操作员拖动主臂，从臂同步复刻动作，完成夹爪闭合或接触式点检动作。

85 s

回车返航

操作员确认作业完成并收回机械臂；按回车后底盘沿反向里程计目标返回起点。

DEMO COMMANDS / 演示入口
主臂端：python3 ~/master_joint_node.py --ros-args -p config_path:=$HOME/arms/Panthera-HT_SDK/panthera_python/robot_param/Leader.yaml 车端：　GRIP=1 bash ~/run_full_demo.sh 降级：　GRIP=0 bash ~/run_full_demo.sh　（夹爪不参与演示）

现场以部署到车端的脚本版本为准。启动顺序先主臂节点、后车端任务，任一链路自检失败都不强行进入演示。

09 / BOUNDARY

风险与边界

把系统能力说准确，比把 demo 说得更“智能”更重要。

风险点可能表现当前处理后续动作
里程计累积误差长距离后停车点偏移控制演示距离；到点后低速零速保持加入轮速标定与二次定位
雷达盲区 / 低矮障碍贴地小物体或特定角度未触发前向扇区阈值 + 人工观察多传感器融合与下视感知
异构臂映射误差关节方向不一致或末端偏差索引对齐、方向修正、幅度缩放关节标定与末端闭环校正
夹爪热与机械卡滞夹持力下降、舵机发热限制连续作业时长；先空载检查更换高扭矩执行器与力反馈
现场光照与反光视觉识别不稳定视觉不进入最终演示主线A/B 光位、深度相机或主动补光
通信中断从臂停在上一目标停止继续下发，主臂端先扶稳心跳超时与自动归位策略
能力边界

不是全自主抓取

当前系统是“自主到达 + 人在环遥操作”。目标识别和抓取策略有实验验证，但最终演示不依赖视觉自动抓取，也不宣称复杂物体泛化能力。

场地边界

不是全场景 SLAM 导航

空旷场地缺少稳定特征，最终以固定起点的里程计航点完成闭环。地图导航能力保留为后续在有边界、有结构的巡检场景中扩展。

10 / SCENARIOS

应用场景

从“看得见”升级到“够得着、操作得了”。

01

变电站 / 配电房

按按钮、开柜门、测温取样；人员留在安全区完成高风险点检。

02

地铁站 / 隧道管廊

夜间巡检、清障、设备复位；减少封闭空间内的人员暴露。

03

化工 / 核工业

从臂进入危险区执行阀门操作与取样，主臂在安全区复刻动作。

04

仓储 / 机房

夜间盘点、货架取放、阀门与开关操作，把移动能力接入作业流程。

05

应急救援 / 安防

先遣侦察、开门、移障；人不在第一时间进入未知环境。

06

教学科研

作为 ROS 2、异构主从、移动操作与边缘 AI 的综合实验平台。

系统真正有价值的不是“车会走”，也不是“机械臂会动”，而是把移动机器人的到达能力 与机械臂的接触作业能力接到同一条任务链上：车把人送到安全观察位，人的动作被安全地延伸到现场。

11 / ROADMAP

后续规划

先把 demo 做稳，再把能力做成产品。

0–1 个月

演示可靠性

完善一键启动、状态自检、异常提示与现场彩排；固定主从零位流程，补齐夹爪温度与机械限位保护。

1–3 个月

感知与定位

在有结构的真实场地接入 SLAM / AMCL / Nav2；加入轮速标定、视觉辅助定位和相机画面叠加。

3–6 个月

作业能力升级

引入末端视觉伺服、力/触觉反馈、多工位任务编排；从“人复制动作”走向“人监督、机器执行”。

DESIGN PRINCIPLE / 设计原则

移动机器人负责到达，机械臂负责作业；
人负责判断，机器负责执行。
