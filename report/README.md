# 网页版项目报告

双击 `index.html` 即可离线打开，不依赖 CDN 或本地服务器。

## 文件

- `index.html`：报告正文与页面结构
- `report.css`：响应式样式、打印 / A4 导出样式
- `report.js`：阅读进度、目录高亮、锚点跳转
- `report-preview.png`：整页预览图
- `report-mobile.png`：移动端预览图
- `report.pdf`：11 页 A4 版本，可直接提交或打印

## 使用

1. 浏览器打开 `index.html`
2. 点击右上角“打印 / 导出 PDF”
3. 目标打印机选择“另存为 PDF”，纸张选择 A4
4. 建议开启“背景图形”，以保留封面和状态色

## 内容口径

- 已跑通：底盘航点、雷达避障、主臂关节流、主从映射代码、一键演示链路
- 联调中：从臂 I2C 实机闭环与现场彩排
- 非最终链路：SLAM / Nav2、HSV / YOLO 视觉抓取

报告不将实验性能力描述为最终演示能力。
