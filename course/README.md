# ROS2 机器人入门课（单页网页）

## 打开方式

直接双击 `index.html` 即可，页面不依赖外部 CDN、图片或网络。

如果需要本地 HTTP 预览（例如测试复制按钮、移动端调试）：

```powershell
node server.js 8766
```

然后打开 `http://127.0.0.1:8766/`。

## 页面内容

- 学习路线：认知 → 环境 → 通信 → 系统实战
- 9 个课程模块：ROS2 世界观、环境搭建、工作空间、节点、话题、服务/动作/接口、参数/Launch/TF、DDS/QoS/分布式、巡检实战
- 3 种架构视图：分层架构、计算图、主从遥操作
- 25 条常用命令：搜索、分类筛选、一键复制
- 实验手册：从供电检查到雷达避障、机械臂动作、主从映射
- 5 道自测题：提交后自动判分并显示解析
- 常见问题：ROS1/ROS2、QoS、多机通信、SLAM 与避障、RDK X5

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 页面内容与结构 |
| `styles.css` | 深色/浅色主题、响应式布局 |
| `app.js` | 目录高亮、学习进度、搜索筛选、复制、架构图交互、自测判分 |
| `server.js` | 可选的本地静态服务器，仅用于预览 |

## 交互

- 右上角切换深色/浅色主题，选择会保存在浏览器本地
- 每个模块右侧复选框可标记完成，进度保存在 `localStorage`
- 侧边栏“重置学习进度”可清空完成状态
- 点击计算图中的节点，右侧会显示该节点的输入、输出和关键参数
- 手机端侧边栏通过左上角菜单按钮打开
